# Bitul & Krishna Moni — Wedding Invitation

A responsive wedding invitation website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — all page sections and content.
- `style.css` — ivory, champagne-gold and black theme, responsive layout, envelope animation.
- `script.js` — guest-name personalization, English/Assamese language switch, countdown, and demo RSVP messages.

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts used in the design; the rest of the site is local.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, e.g. `bitul-krishna-wedding`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## Before sharing the invitation
Replace the sample event details, story text, photo placeholders, and venue placeholder with confirmed information. RSVP currently displays a confirmation on the guest's device only; it does not save or send responses. Connect a form service or backend later if the couple needs a guest list.
